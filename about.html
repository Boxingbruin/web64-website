What Is Web64?

Web64 is an experimental native web browser built for Nintendo 64 with libdragon.

HTML64 parses documents, CSS64 computes supported styles, and the console renders each page directly.

Project Direction

No JavaScript is planned.

The N64 owns browser behavior and page rendering.

The PC acts only as a low-level network bridge.
