Welcome to the tiny web. Web64 uses familiar HTML and CSS, then trims the feature set down to something an N64 can handle happily.

At a glance

Screen

640 x 480, with a 592 x 400 webpage area.

Comfortable page width

A centered 560px shell fits the browser nicely.

Web stack

HTML64, CSS64, inline styles, links, fonts, and sprite images.

JavaScript

Not supported.

Where to go
