A Real N64 Browser

Web64 is a native web browser for Nintendo 64. The console parses pages, resolves styles, runs the network stack, and renders the result itself.

The computer is a modem, not a browser proxy.

Open the developer docs

Inside Web64

HTML64, CSS64, and asset parsers

HTTP, TCP, DNS, UDP, and ICMP

IPv4, Ethernet, and ARP

USB cartridge link-device interface

Built-in fonts and PNG images

What You Need

1. The web64.z64 browser ROM.

2. A supported USB-enabled flash cartridge.

3. The Web64 modem app, which creates a TAP interface and provides routing and NAT.

4. An HTTP website built with the supported HTML64 and CSS64 feature set.
