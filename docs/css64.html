CSS64

CSS64 supports a practical slice of CSS for colorful fixed-screen pages. Use this page as the quick compatibility check.

Selectors

Supported

Element selectors, .classes, #ids, and comma-separated selector lists.

Skipped

Combinators, descendant selectors, pseudo-classes, and attribute selectors.

Supported properties

Type
  color  font-family  font-size
  line-height  text-align

Layout
  display  vertical-align
  width  height  min-width
  max-width  margin  padding

Backgrounds
  background-color
  background-image
  background-repeat
  background-size
  background-position

Edges and effects
  border  border-width
  border-style  border-color
  border-radius  outline
  outline-offset  box-shadow

Position and input
  position  top  right
  bottom  left  z-index
  cursor

Border styles

CSS64 supports the full set of classic CSS border styles. These are real rendered borders.

none
hidden
dotted
dashed
solid
double
groove
ridge
inset
outset
border-style: none | hidden | dotted |
  dashed | solid | double | groove |
  ridge | inset | outset;

none and hidden reserve no visible border width. The remaining styles use the configured border width and color.

Border radius

Use one radius for every corner, or shape each corner independently.

all corners
per-corner
border-radius: 18px;

border-top-left-radius: 24px;
border-top-right-radius: 4px;
border-bottom-right-radius: 24px;
border-bottom-left-radius: 4px;

Box shadows

outer shadow
inset shadow
box-shadow:
  5px 5px 6px rgba(0,0,0,0.35);

box-shadow:
  inset -3px -3px 8px rgba(0,0,0,0.25);

Background images

one positioned sprite
background-image:
  url("images/crystal.sprite");
background-repeat: no-repeat;
background-position: 95% 50%;

Not part of CSS64

Flexbox, Grid, media queries, transitions, animations, transforms, and sticky positioning are not supported.
