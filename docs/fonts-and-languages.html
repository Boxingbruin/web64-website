Fonts and Languages

Web64 ships with a large font shelf. Pick a family, add a fallback, and keep the number of families used on one page reasonable.

Built-in families

Abaddon          AT01
Avenue Pixel     BitPotion
Chunky Sans      Cyborg Sister
Divinity         DM Sans
Droid Sans       Enter Command
Fibberish        Fira Mono Bold
Fortzilla        Lato
Liver            m3x6
m5x7             m6x11 plus
Minimal Pixel    Monogram
Pacifico         Poco
Roboto Medium    Roundabout
Silver           Slab
Timesplitter     Unbalanced
Xolonium

The desktop compatibility sheet calls these “Web64 Roundabout”, “Web64 Slab”, and so on.

Available sizes

16px - body copy

20px - lead text

24px - section title

32px - page title

40px - big cartridge energy

Using a family

body {
  font-family:
    "Roundabout",
    "Chunky Sans",
    at01;
}

Web64 walks the list from left to right and uses the first built-in family it recognizes.

Languages and symbols

Glyph coverage varies by font. Test the exact accents, symbols, or alphabet your site needs, then keep a broad fallback at the end of the list.
