Images and Assets

Web64 loads converted sprite resources. Keep paths simple, set dimensions, and reuse small assets when you can.

What works

HTML images

img with src, alt, width, and height

CSS backgrounds

background-image with repeat, size, and position controls

Runtime format

Converted .sprite resources

Image records

Up to 32 images in one parsed page

Image example

<img
  src="images/crystal.sprite"
  alt="Purple crystal"
  width="26"
  height="26"
>

How paths are resolved

img src

Relative to the HTML page URL.

External CSS url()

Relative to the stylesheet URL.

Inline style url()

Relative to the HTML page URL.

Good habits

Set width and height, keep the intended aspect ratio, and avoid loading a long parade of large one-off sprites on the same page.
