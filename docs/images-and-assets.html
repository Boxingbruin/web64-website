Assets

Prepare website assets for Web64 with web64-build from https://github.com/Boxingbruin/web64-tools.

Image sources

Current format

Web64 currently supports .png, .jpg, .jpeg and .webp image files.

HTML image example

<img
  src="images/crystal.png"
  alt="Purple crystal"
  width="26"
  height="26"
>

Use the normal source image path in your HTML. Web64 requests the generated Web64 asset automatically.

Build website assets

Get web64-build from:

https://github.com/Boxingbruin/web64-tools

Run it on the root directory of your website before uploading or testing the site with Web64:

./web64-build build /path/to/website

You can also run it from inside your website directory:

/path/to/web64-build build .

The tool scans the website recursively and creates Web64-compatible .sprite files beside supported source images.

images/crystal.png
images/crystal.sprite

Your HTML and CSS continue to reference the original image file. The generated .sprite file is used by Web64.

Useful commands

Build

web64-build build [directory] generates missing or outdated Web64 assets.

Check

web64-build check [directory] checks the project without changing any files.

Clean

web64-build clean [directory] removes generated Web64 assets.
