HTML64

HTML64 keeps the useful pieces for small, visual pages. Unsupported tags are skipped while their visible text is usually kept.

Supported elements

Document
  body  title  link

Text
  p  h1-h6  br  hr  pre
  strong/b  em/i  span

Interactive and media
  a  button  img

Lists and containers
  ul  ol  li  div
  address  article  aside
  blockquote  footer  header
  main  nav  section  table

Supported attributes

Every styled element

id, class, and style

Links

href

Images

src, alt, width, and height

Stylesheets

link rel="stylesheet" href="..." inside head

Things Web64 leaves out

script

JavaScript content is not rendered or executed.

Unknown tags

The tag is ignored; visible text can still appear.

Built-in limits

Runs           1024
Links           128
Images           32
Stylesheets       8
Element depth    16
